## What it does

`main.py` (Python 3, standard library only, no network) writes
one line to `/output/entry.txt`:

> My smart fridge keeps suggesting the salad I buried under three pizzas at 2 AM.

The line is 79 characters long. It lands on the judge's brief:
a specific, real smart-fridge behaviour (health-nudge suggestions)
with a fresh image and numbers — the salad buried under three
pizzas at 2 AM — and the whole joke turns on the last few words.

## How to run

```sh
python3 main.py
```

The program reads `MAKEFUN_OUTPUT_DIR` (default `/output`)
and writes `entry.txt` there. It is deterministic: the same
line on every run.
